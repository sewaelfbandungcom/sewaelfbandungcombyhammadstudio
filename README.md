## 🌟 Tentang Sewa Elf Bandung

**Sewa Elf Bandung by Amoora Group** hadir sebagai penyedia layanan rental kendaraan rombongan terdepan di Bandung. Kami melayani kebutuhan perjalanan wisata, *study tour*, liburan keluarga, *company gathering*, ziarah religi, hingga *carter drop-off* antar kota.

Didukung oleh armada prima berstandar **Euro4**, interior bersih wangi ber-AC dingin, fasilitas audio karaoke & charger, serta pengemudi berpengalaman yang santun dan menguasai rute.

4. **Pemberian Kontak Driver H-1:** Detail pengemudi diinfokan H-1 dan siap standby di lokasi penjemputan.

## 🛠️ Tech Stack & Pengembangan

- **Framework:** Next.js 16.3 (App Router, Turbopack)
- **UI & Styling:** Tailwind CSS v4.0 with Custom Brand Tokens
- **Icons:** Phosphor Icons, HugeIcons, Iconify Design
- **Type Safety:** TypeScript 5.0
- **SEO & Performance:** Schema.org LocalBusiness/AutoRental, OpenGraph, dynamic metadata

### Menjalankan di Lokal

```bash
# Clone repository
git clone https://github.com/sewaelfbandungcom/sewaelfbandungcombyhammadstudio.git

# Masuk direktori
cd sewaelfbandung

# Install dependensi
npm install

# Jalankan server development
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser Anda.
